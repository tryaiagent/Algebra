Linear equations

  1. Solve \(3x + 5 = 20\).
    1. Start with \(3x + 5 = 20\).
    2. Subtract 5 from both sides: \(3x = 15\).
    3. Divide both sides by 3: \(x = 5\).
    4. Check: \(3(5) + 5 = 20\) which is true.
    Answer: 5
  2. Solve \(4.2z - 3.5 = -9.1\).
    1. Start with \(4.2z - 3.5 = -9.1\).
    2. Add 3.5 to both sides: \(4.2z = -5.6\).
    3. Divide both sides by 4.2: \(z = -\frac{5.6}{4.2}\).
    4. Simplify the fraction: \(-\frac{56}{42} = -\frac{4}{3}\).
    5. Check: \(4.2\left(-\frac{4}{3}\right) - 3.5 = -9.1\) which is true.
    Answer: -\frac{4}{3}

Equations with variables on both sides

  1. Solve for \\(x\\): \\(3x + 5 = 2x + 12\\).
    1. Subtract \\(2x\\) from both sides: \\(x + 5 = 12\\).
    2. Subtract \\(5\\) from both sides: \\(x = 7\\).
    3. Check: \\(3\\times7 + 5 = 26\\) and \\(2\\times7 + 12 = 26\\), so the solution is correct.
    Answer: x = 7
  2. Solve for \\(x\\): \\(4(2x - 3) = 3(x + 5) + 2x\\).
    1. Expand both sides: \\(8x - 12 = 3x + 15 + 2x\\).
    2. Combine like terms on the right: \\(8x - 12 = 5x + 15\\).
    3. Subtract \\(5x\\) from both sides: \\(3x - 12 = 15\\).
    4. Add \\(12\\) to both sides: \\(3x = 27\\).
    5. Divide by \\(3\\): \\(x = 9\\).
    6. Check: \\(4(2\\times9 - 3) = 60\\) and \\(3(9 + 5) + 2\\times9 = 60\\), confirming the solution.
    Answer: x = 9

Equations involving fractions

  1. \(\frac{x+2}{3}=5\)
    1. Multiply both sides by 3 to clear the denominator: \(3\times\frac{x+2}{3}=3\times5\)
    2. Simplify the left side: \(x+2=15\)
    3. Subtract 2 from both sides: \(x=15-2\)
    4. Result: \(x=13\)
    Answer: x = 13
  2. \(\frac{3x+1}{5}=\frac{x-2}{2}\)
    1. Clear the fractions by multiplying both sides by the LCD 10: \(10\times\frac{3x+1}{5}=10\times\frac{x-2}{2}\)
    2. Simplify each term: \(2(3x+1)=5(x-2)\)
    3. Distribute: \(6x+2=5x-10\)
    4. Subtract 5x from both sides: \(x+2=-10\)
    5. Subtract 2 from both sides: \(x=-12\)
    6. Result: \(x=-12\)
    Answer: x = -12

Simultaneous equations

  1. Solve the simultaneous equations \(3x + 4y = 24\) and \(x - 2y = -2\).
    1. Write the two equations: \(3x + 4y = 24\) and \(x - 2y = -2\).
    2. From the second equation, express \(x\) in terms of \(y\): \(x = 2y - 2\).
    3. Substitute this expression for \(x\) into the first equation: \(3(2y - 2) + 4y = 24\).
    4. Expand and simplify: \(6y - 6 + 4y = 24\) \(\rightarrow\) \(10y - 6 = 24\).
    5. Add 6 to both sides: \(10y = 30\).
    6. Divide by 10: \(y = 3\).
    7. Substitute \(y = 3\) back into \(x = 2y - 2\): \(x = 2\times 3 - 2 = 4\).
    8. Check: \(3\times4 + 4\times3 = 12 + 12 = 24\) and \(4 - 2\times3 = 4 - 6 = -2\). Both are true.
    9. Therefore, the solution is \(x = 4,\; y = 3\).
    Answer: x = 4, y = 3
  2. Solve the simultaneous equations \(4x + y = 18\) and \(2x - 3y = 16\).
    1. Write the equations: \(4x + y = 18\) and \(2x - 3y = 16\).
    2. Multiply the second equation by 2 to make the coefficient of \(x\) match the first: \(4x - 6y = 32\).
    3. Subtract the first equation from this new equation to eliminate \(x\): \((4x - 6y) - (4x + y) = 32 - 18\).
    4. Simplify: \(-7y = 14\).
    5. Divide by -7: \(y = -2\).
    6. Substitute \(y = -2\) into the first equation: \(4x + (-2) = 18\).
    7. Simplify: \(4x - 2 = 18\).
    8. Add 2: \(4x = 20\).
    9. Divide by 4: \(x = 5\).
    10. Check in the second equation: \(2\times5 - 3\times(-2) = 10 + 6 = 16\). True.
    11. Thus the solution is \(x = 5,\; y = -2\).
    Answer: x = 5, y = -2

Factorisation

  1. Factor the expression \(6x + 9\).
    1. Identify the greatest common factor of the terms, which is 3.
    2. Divide each term by 3: \(6x ÷ 3 = 2x\) and \(9 ÷ 3 = 3\).
    3. Write the expression as \(3(2x+3)\).
    4. Check by expanding: \(3(2x+3)=6x+9\).
    Answer: 3(2x+3)
  2. Factor the quadratic \(x^2 + 4x - 5\).
    1. We need two numbers that multiply to \(-5\) and add to \(4\).
    2. The numbers \(5\) and \(-1\) satisfy these conditions because \(5\times(-1) = -5\) and \(5+(-1)=4\).
    3. Rewrite the middle term using these numbers: \(x^2 + 5x - x - 5\).
    4. Group the terms: \((x^2 + 5x) + (-x - 5)\).
    5. Factor each group: \(x(x+5) -1(x+5)\).
    6. Factor out the common binomial \((x+5)\): \((x+5)(x-1)\).
    7. Check by expanding: \((x+5)(x-1)=x^2 - x +5x -5 = x^2 +4x -5\).
    Answer: (x+5)(x-1)

Exponents / indices

  1. Simplify \(3^0 \times 5^2 \times 5^{-1}\).
    1. Use the zero exponent rule: \(3^0 = 1\).
    2. Apply the positive exponent: \(5^2 = 25\).
    3. Apply the negative exponent: \(5^{-1}=\frac{1}{5}\).
    4. Multiply the factors: \(1 \times 25 \times \frac{1}{5}= \frac{25}{5}=5\).
    Answer: 5
  2. Simplify \(\frac{(2^3 \cdot 3^{-2})^2}{2^{-1} \cdot 3^4}\).
    1. First simplify the numerator using the power of a product rule: \((2^3 \cdot 3^{-2})^2 = (2^3)^2 \cdot (3^{-2})^2\).
    2. Apply the power‑to‑a‑power rule: \((2^3)^2 = 2^{3\times2}=2^6\) and \((3^{-2})^2 = 3^{-2\times2}=3^{-4}\).
    3. So the numerator becomes \(2^6 \cdot 3^{-4}\).
    4. Write the denominator as given: \(2^{-1} \cdot 3^4\).
    5. Now divide the powers with the same base: \(\frac{2^6}{2^{-1}} = 2^{6-(-1)} = 2^7\) and \(\frac{3^{-4}}{3^4}=3^{-4-4}=3^{-8}\).
    6. Combine the results: \(2^7 \cdot 3^{-8}\).
    7. Replace negative exponent with a reciprocal: \(3^{-8}=\frac{1}{3^8}\).
    8. Thus the expression is \(\frac{2^7}{3^8}=\frac{128}{6561}\).
    Answer: \frac{128}{6561}

Polynomial questions

  1. Expand and simplify \((2x+3)(x-4)\).
    1. Write down the product: \((2x+3)(x-4)\)
    2. Multiply each term in the first bracket by each term in the second: \(2x\cdot x + 2x\cdot(-4) + 3\cdot x + 3\cdot(-4)\)
    3. Simplify each product: \(2x^{2} -8x +3x -12\)
    4. Combine like terms: \(2x^{2} -5x -12\)
    Answer: \(2x^{2} -5x -12\)
  2. Substitute \(x = 2y - 1\) into \(P(x)=3x^{2} -2x +5\) and simplify.
    1. Write the polynomial with the substitution: \(P(2y-1)=3(2y-1)^{2} -2(2y-1) +5\)
    2. Expand the square: \((2y-1)^{2}=4y^{2} -4y +1\)
    3. Multiply by 3: \(3(4y^{2} -4y +1)=12y^{2} -12y +3\)
    4. Distribute -2: \(-2(2y-1) = -4y +2\)
    5. Add all parts: \(12y^{2} -12y +3 -4y +2 +5\)
    6. Combine like terms: \(12y^{2} -16y +10\)
    Answer: \(12y^{2} -16y +10\)

Radical / surd questions

  1. Simplify the surd \(\sqrt{48}\).
    1. Factor 48 as 16\times3.
    2. Use \(\sqrt{ab}=\sqrt{a}\,\sqrt{b}\) to write \(\sqrt{48}=\sqrt{16}\sqrt{3}\).
    3. Since \(\sqrt{16}=4\), the expression becomes \(4\sqrt{3}\).
    4. Therefore the simplified form is \(4\sqrt{3}\).
    Answer: \(4\sqrt{3}\)
  2. Simplify \(5\sqrt{20} - 3\sqrt{45}\).
    1. Write \(\sqrt{20}=\sqrt{4\times5}=2\sqrt{5}\).
    2. Multiply the coefficient: \(5\times2\sqrt{5}=10\sqrt{5}\).
    3. Write \(\sqrt{45}=\sqrt{9\times5}=3\sqrt{5}\).
    4. Multiply the coefficient: \(3\times3\sqrt{5}=9\sqrt{5}\).
    5. Subtract the like surds: \(10\sqrt{5}-9\sqrt{5}=\sqrt{5}\).
    6. Thus the simplified result is \(\sqrt{5}\).
    Answer: \(\sqrt{5}\)

Rational expressions and equations

  1. Simplify the algebraic fraction \(\frac{2x^2 - 8}{4x}\).
    1. Factor the numerator: \(2x^2-8 = 2(x^2-4) = 2(x-2)(x+2)\).
    2. Write the denominator as \(4x = 2\cdot2x\).
    3. Cancel a common factor of 2 from numerator and denominator: \(\frac{2(x^2-4)}{4x}=\frac{x^2-4}{2x}\).
    4. The fraction is now simplified; you could also write \(\frac{x^2-4}{2x}=\frac{x}{2}-\frac{2}{x}\) if desired.
    Answer: \frac{x^2-4}{2x}
  2. Solve for \(x\): \(\frac{5}{x-1} + \frac{2}{x+2} = \frac{7}{x^2 + x -2}\).
    1. Factor the quadratic denominator: \(x^2+x-2 = (x-1)(x+2)\).
    2. Multiply every term by the common denominator \((x-1)(x+2)\) to clear fractions.
    3. This gives: \(5(x+2) + 2(x-1) = 7\).
    4. Expand: \(5x+10 + 2x-2 = 7\) which simplifies to \(7x+8 = 7\).
    5. Subtract 8: \(7x = -1\).
    6. Divide by 7: \(x = -\frac{1}{7}\).
    7. Check that \(x\neq 1\) and \(x\neq -2\); \(-\frac{1}{7}\) is allowed, and substitution satisfies the original equation.
    Answer: x = -\frac{1}{7}

Exponential equations

  1. Solve for \(x\): \(2^x = 16\).
    1. Write 16 as \(2^4\)
    2. Since the bases are the same, equate the exponents: \(x = 4\)
    3. Check: \(2^4 = 16\)
    Answer: \(x = 4\)
  2. Solve for \(x\): \(5^{2x-1} = 125\).
    1. Write 125 as \(5^3\)
    2. Set the exponents equal: \(2x-1 = 3\)
    3. Solve for \(x\): \(2x = 4\) so \(x = 2\)
    4. Check: \(5^{2\cdot2-1}=5^3=125\)
    Answer: \(x = 2\)
